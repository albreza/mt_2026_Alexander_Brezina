# Téma

Spracovanie **dohodnutej témy** z oblasti mobilných technológií – napr. porovnanie frameworkov,
nové API platformy, bezpečnosť, on-device AI, BLE, NFC, 5G/6G …

## Výstup

Do tohto priečinka uložte:

- **prezentáciu** na prednášku – PDF, Keynote, PowerPoint …,
- **popis použitia LLM** – samostatný súbor alebo súčasť prezentácie
  (nástroje, na čo, kľúčové prompty, čo ste overili a upravili sami),
- **zoznam zdrojov** – v prezentácii alebo samostatne.
