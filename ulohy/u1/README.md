# U1 – Návrh vlastného projektu

Vymyslite si **vlastnú mobilnú aplikáciu**, ktorú by ste mohli riešiť počas celého semestra ako projekt.
Ideálne by mala riešiť reálny problém pre reálnych používateľov.

Z popisu by malo byť jasné:

- ako sa aplikácia volá a aký problém rieši,
- pre koho je určená,
- aké sú jej hlavné funkcie (zhruba 3–5),
- čo je na nej **mobilné** – aké možnosti zariadenia využíva (senzory, poloha, kamera, offline režim, notifikácie ...),
- aká je jej architektúra – aký má **backend / cloud**, kde sú dáta, aké služby alebo API používa.

Rozsah zhruba 1/2 až 1 strana. Formu si zvoľte sami (Markdown, PDF, doc, ...) – riešenie uložte do tohto priečinka. Na cvičení svoj návrh krátko predstavíte.
